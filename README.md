# C949 Study Drill

A study tool for **WGU C949: Data Structures and Algorithms I**. It's one HTML file that runs in the browser, with nothing to install.

**Live site:** https://ned777.github.io/c949/

## Features

- **439 practice questions** across 14 topics, from Big O and sorting to hash tables, trees, graphs, and Python.
- **Every choice explained:** after you answer, it shows why the right answer is right and why each wrong one is wrong.
- **Study notes built in:** each question links to the notes section that covers it.
- **20, 40, or 60 question runs** with no repeats and a score at the end. New questions come up first.
- **Practice exam:** 60 questions weighted like the real exam (29% / 31% / 40%), scored by section and topic.
- **Progress tracking:** saves in your browser and lets you resume a run, flag questions, and re-drill your misses.
- **Flashcards and a one-page cheat sheet.**

## Topics

Algorithm characteristics · recursion · Big O · linear and binary search · bubble, selection, insertion, merge, quick, heap, counting, radix, bucket, and shell sort · arrays · linked lists · stacks · queues · deques · hash tables and collisions · sets · trees, BSTs, and traversals · AVL, red-black, and B-trees · heaps · graphs, BFS/DFS, Dijkstra, and Bellman-Ford · data flow diagrams · Python and OOP basics

## Use it

Open the live site, or download `index.html` and open it in any browser.
